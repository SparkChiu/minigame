# 《逃出疯人院》场景探索 Demo v2.0.1

这是一个独立的俯视角场景交互原型。它保留了原版 Demo 的行动、体力、药物负荷、信任、怀疑、关系、物品与线索机制，并把主要体验改造成可控制角色在场景中移动和互动。

## 开始游戏

直接用 Chrome、Edge 或 Safari 打开 `index.html`。游戏不需要安装，也不需要联网。

## 操作

- 电脑：使用 `WASD` 或方向键移动，靠近目标后按 `E` 或空格互动。
- 手机 / 平板：使用画面下方的方向按钮移动，点击“互动”。
- 走路与切换场景不消耗行动；调查、社交、训练、休息及每次进入小卖部后的首次购买会消耗行动。
- 游戏会自动保存，也可以使用右上角的“保存”按钮。

## 本版内容

- 四个可探索场景：东区病房、公共走廊、康复花园、院内小卖部。
- 三名可互动角色：护士林、老张、陈伯。
- 晨间治疗、行动与体力、药物负荷、信任与怀疑、隔离处分、成长、人物关系、背包、线索、跨天循环。
- 第一天引导链：完成治疗 → 检查腕带 → 认识院友 → 抄录周期治疗安排 → 自由行动。
- 茶包和点心可以推动人物关系并获得后续调查资源。

## 原型边界

v2.0.1 修复了场景切换时角色可能落在碰撞体内的问题，并为旧存档增加自动脱困保护。当前版本主要验证“角色控制 + 场景探索 + 原有数值系统”的新体验；工疗室与完整逃离结局会在这套场景框架上继续扩展。
