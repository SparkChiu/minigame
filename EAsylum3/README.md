# 《逃出疯人院》管理叙事 Demo v3.0

这是一个独立于俯视角版本的新原型。它采用横向剖面场景与点击热点的管理交互：玩家不直接控制角色走路，而是在不同区域选择床铺、人物、公告栏、工作台等目标，把每天有限的时间投入调查、关系、工作和恢复。

## 开始游戏

解压后用 Chrome、Edge 或 Safari 打开 `index.html`。不需要安装或联网。

## 核心规则

- 每个行动推进游戏时间，切换区域不推进时间。
- 工疗室在周二、周四、周六开放；行政登记在周一、周三、周五开放。
- 晨间治疗结束前不能执行其他行动。
- 药物负荷越高，行动耗时和额外体力消耗越高，能力成长越慢。
- 怀疑达到 60 会立刻中断当前行动并触发小黑屋事件。
- 小卖部每次打开后的第一次购买推进 1 小时，之后连续购买不再推进时间。
- 游戏没有逃离天数上限，并支持本机自动存档与手动保存。

## Demo 目标

把六层调查线索连接起来：错误腕带编号、每周治疗排班、异常夜班记录、重复药品批次、病历复写页和旧楼检修路线。线索需要正确的星期、物品、人物关系和状态才能获得。完成后会展示三个后续逃离方向。

## 视觉说明

场景美术为本项目专门生成的原创 16-bit 风格医院环境，不包含其他游戏的角色、界面或原始素材。
