# 《逃出疯人院》最终版 v3.0

本版本采用“双母版”结构：

- 内容、剧情和规则以可玩 Demo v1.27 为母版。
- 交互和表现以 v3.0“玩法垂直切片”为母版。

玩家不直接控制角色走路，而是通过左侧区域切换、中央横向场景热点、时间轴、右侧状态栏、行动弹窗和底部反馈日志安排每天的生活。

## 开始游戏

解压后使用 Chrome、Edge 或 Safari 打开 `index.html`。不需要安装或联网。

## v3.0 交互形式

- 左侧切换院内区域，切换区域不消耗时间。
- 中央场景以闪烁热点提供床铺、人物、工作台、文件、电话等互动目标。
- 每次行动通过弹窗选择，并同时结算院内时间、行动次数、体力和其他状态。
- 顶部显示天数、星期、时间、体力、清醒、行动与积分。
- 右侧显示每日系统信息、院方评价和当前场景人物。
- “今天发生了什么”固定在底部，按最旧到最新排列并自动滚动。
- 随身记录集中查看线索、物品、关系、五维养成、技能树和规则。

## 已迁入的 v1.27 内容

- 不限天数的一周七日循环。
- 晨间治疗概率结果、药物负荷分段、设施封锁和小黑屋。
- 11 个院内生活区域，其中 10 个横向场景区域与 1 个小卖部窗口。
- 老张、陈伯、小文、护士林、保安赵卫国 5 条完整关系线。
- 14 类物品；数量为 0 时不显示，物品说明不提前透露人物或路线用途。
- 23 条四层情报、周期排班表和自动交叉印证。
- 三只档案盒、文件袋流向、夜班排班、三色压力阀等谜题内容。
- 合法复核、维修通道、媒体公开三条可完成的离院路线。
- 第 3、6、9 天剧情分支、保安交班证词与隐藏旧报社剧情。

## 五维养成与技能树

五维包括体能、技能、沟通、洞察和人脉。能力升级、关系里程碑、交叉印证与关键证据会提供养成点数。

技能树分为生存、调查、人脉三支，共 12 个节点。节点会实际改变体力消耗、过夜代谢、怀疑增长、关系成长、区域门槛、谜题要求与离院条件。
