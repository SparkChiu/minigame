# 铸剑大师 · 无尽契约

本地 HTML 游戏 demo，支持手机竖屏。无需联网或安装组件。

## 开始与操作

- 打开同级目录的 `铸剑大师.html` 即可。图片与代码已内嵌，复制这一个文件也能玩。
- 源码版可直接打开本目录的 `index.html`，保留 CSS、JS 文件和 assets 文件夹。
- 点击「点燃熔炉」开始。手机底部固定加热、挥锤、收剑按钮；入神期间长按挥锤连续敲击，松手停止。普通长按只敲一次。
- 键盘：E 加热、空格挥锤、Q 入库、P / Esc 暂停。音效默认关闭，点击 ♪ 开启。
- 打开商店、说明或遗物详情会暂停。隐藏页面自动暂停。刷新或重新开始会清空本局，养成为局内效果。
- 手机文件应用若只显示静态预览，需选择“在浏览器中打开”。

## 无尽关卡

第五关不再结算胜利。交清本关贡品就进入下一关，直到超时失败；目标是走得更远。

前五关基础贡品为 480 / 850 / 1400 / 2200 / 3600。第六关起每关增长 24%；每五关再追加一次 20% 的永久贡品增长。

每五关为巨龙威压关，额外增加 3.5 个百分点的碎裂风险。普通关也逐渐提高风险。贡品基础期限每五关缩短 3 秒，由 105 秒逐渐缩至 70 秒，沙瓶可以缓解压力。

| 1 | 480 | 105 秒 | 否 |
| 5 | 3,600 | 105 秒 | 是 |
| 10 | 12,665 | 102 秒 | 是 |

## 剑与风险

- 无限剑胚，初始价值 40。至少成功锻造一次才能入库、兑换。剑架容量 6 把。
- 普通成功挥锤使剑值增加约 14%–24%，加上固定增值；基础暴击概率 12%，暴击额外增加挥锤前价值的 20%。
- 同一把剑正常成功锻造 10 次后蓄满入神，第 11 锤开启基础 4.5 秒安全时间。期间剑身炫彩、保持温热、不会碎裂，可长按连续敲击。入神期间不重复蓄力。
- 入神每锤只增加约 4.5%–9.5% 加固定增值；暴击额外增加 10%。保留连续成功的爽感，同时控制无风险收益。
- 碎裂概率随该剑总锻造次数、关卡与低温上升。基础红热风险 4%，每次成功锻造增加 2.2 个百分点，正常风险范围 2.5%–70%。界面实时显示下一锤概率。
- 碎剑只损失当前剑；库存与遗物等级保留。
- 点击库存剑选择贡品；可多选。合计满足要求后献贡，整把剑收走，不返还差价。
- 单选一把库存剑，点击「取回锻造」可继续强化。剑值、成功次数、入神蓄力均保留，剑温归零；当前已锻造的剑自动换入剑架。取回不会洗掉风险。

## 遗物养成

每关随机出现三个遗物种类。已有遗物也会再次出现，可交剑升级，等级没有固定上限。每关最多兑换两次，每件当关报价仅能买一次。换关后刷新货品与兑换额度。

所有升级都会增加炉火共鸣：每一级让新剑初值与每锤固定增值乘以 **1.08**。专属效果随等级增强，但多数逐渐趋近上限，避免堆出永久免碎或无限时间。

第六关后普通贡品每关增长 24%，每关两次升级的共鸣最多增长 16.64%。专属效果能帮助抵消差距，但长期无法靠共鸣轻松追平全部压力。

| 遗物 | 首关初次价格 | 专属养成方向 |
| --- | ---: | --- |
| 磐石之锤 | 260 | Lv.1 降低 3.5 个百分点风险，逐渐接近 10 个百分点 |
| 余烬风箱 | 180 | 逐渐接近冷却减缓 50%、加热时间缩短 60% |
| 龙眼石 | 420 | 暴击概率逐渐从 12% 接近 42% |
| 虹彩棱镜 | 650 | 入神逐渐从 4.5 秒接近 7.5 秒 |
| 旧王印章 | 380 | 后续关卡贡品减免逐渐接近 25%；当关报价不变 |
| 不碎之誓 | 520 | Lv.1 / 2 / 4 / 8… 分别获得每关 1 / 2 / 3 / 4… 次护盾 |
| 星铁碎片 | 300 | 每锤基础固定增值逐渐从 9 接近 57，再乘共鸣 |
| 漏时沙瓶 | 340 | 每关额外时间逐渐接近 30 秒；当关只补新增部分 |
| 初火之种 | 220 | 新剑基础初值逐渐从 40 接近 160，再乘共鸣 |

交易价格随关卡和已有等级上涨，约为：首关价格 ×（当前基础贡品 / 480）^0.9 ×（1 + 当前等级 × 0.22），向上取整到 10。

商店显示当前等级、升级后的实际效果和支付剑。每次都支付完整的一把剑，无差价返还。用高值剑升级，也意味着少一把能用来献贡的资源。

## 文件

- `game-core.js`：无尽关卡、风险、贡品与遗物升级规则。
- `game.js`：界面、像素动画、音效和触屏操作。
- `style.css`、`mobile.css`、`endless.css`：桌面、竖屏与升级界面样式。
- `assets/forge.png`：imagegen 内置工具生成的像素锻造坊。
- assets 内另有八个可复用的像素 SVG 图标，生成提示词见 `ART-PROMPT.txt`。
- 具体数值模拟结果与限制见 `BALANCE.md`。

## 验证

通过 23 项规则检查，包括连续推进 100 关、已有遗物重复升级、当关两次兑换限制、递增价格、印章保持当关报价、沙瓶增量加时、护盾次数、取回剑不重置风险，以及入神保护。

通过 12 项模拟界面与触控检查，包括点击去重、长按仅在入神连击、松手和取消停止、多指处理、弹窗暂停、取回锻造、商店兑换次数，以及第五关献贡后进入第六关。

完成 750 局自动数值模拟。模拟不等同于真人试玩，不能证明最终难度已达到所有玩家的预期。当前环境的本机预览连接超时，尚未完成真实浏览器画面与手机真机实测。
