# 《逃出疯人院》可玩 Demo v1.13

这是从 Vertical Slice 扩展出来的完整小型 Demo。玩家从第 1 天开始经营院内生活，在第 15 天转院前完成离院准备，并达成结局。

## 运行方法
1. 解压 ZIP。
2. 打开文件夹中的 `index.html`。
3. 推荐使用 Chrome / Edge。
4. 游戏会使用浏览器 `localStorage` 自动保存，也可以点击右上角 💾。

## Demo 的完整流程
- 序章：发现自己的身份和病历不一致。
- 每天处理晨间治疗。
- 每天拥有 4 次自由行动。
- 工作赚院内积分和材料。
- 训练体能、提升工作技能、社交和观察。
- 帮助病友，发展老张、陈伯、小文和护士林的关系。
- 通过小卖部购买生活用品与电话卡。
- 收集线索，最终取得 3 份关键证据：
  - 被改动的转院单
  - 病历原件
  - 私人付款记录
- 建立院外联络。
- 准备离院路线。
- 在第 15 天以前选择一种结局：
  1. 合法离院：申诉复核，从正门离开。
  2. 夜间离院：从维修通道离开，再在院外公开证据。

## 这版重点验证
这不是潜行解谜 Demo，而是一个“经营成果最后兑现为逃离”的 Demo：
日程经营 → 能力成长 → 工作与物资 → 关系经营 → 情报与证据 → 离院方案 → 结局

## v1.1 改进

- 离院页会逐项显示已满足和仍缺少的条件。
- 新情报、关键证据与普通行动拥有即时可见反馈。
- “今天发生了什么”集成进顶部状态栏，最新记录常驻，并可展开滚动查看。
- 移动端保留天数、时段、剩余行动与转院倒计时。
- 改进自动存档、旧存档兼容、新游戏覆盖确认与键盘操作。
- `Alt + 1` 到 `Alt + 6` 可快速切换六个功能页。

## v1.2 日志顺序优化
- “今天发生了什么”改为按最旧到最新排列，最新记录固定显示在最下方。
- 展开日志或新增记录后，日志区会自动滚动到底部。
- 旧版存档会自动转换日志顺序，不影响继续游戏。

## v1.3 行动窗口优化
- 移除每日行动选择窗口右上角的 × 按钮。
- 在全部行动选项下方增加“关闭窗口”，返回时不会执行行动。
- 继续支持按 `Esc` 关闭行动窗口。

## v1.4 信息反馈与内容扩充
- “今天发生了什么”移入“今天”页首，改为常驻、醒目的主反馈面板。
- 每次行动会明确显示体力、行动次数、信任、怀疑、药物负荷、积分、技能、关系、物品和线索等变化。
- “建议下一步”改为每日轮换的玩法 Tips，只说明规则和系统信息，不再标记地点或引导操作。
- 增加小文纸条、临时检查、维修阀门三段剧情分支，不同选择会影响关系、信任、怀疑和线索。
- 增加餐盘编号、编目便签、求助纸条、骑缝章四类新线索。
- 增加“三只档案盒”逻辑谜题；正确推理后才能取得病历原件，错误选择会消耗行动并增加怀疑。
- 增加多种线索组合与院外联络方式，使同一目标可以通过不同剧情路径达成。

## v1.5 养成与手机信息优化
- “养成”页右侧新增“当前进度”卡片，与全局离院进度和检查项实时同步。
- 玩家姓名上方的角色图片替换为 Emoji 头像，界面更轻量、清晰。
- 手机顶部保存按钮旁新增“今日状态”，实时显示体力、药物负荷、信任和怀疑。

## v1.6 信息合并与移动端品牌栏
- “养成”页将 Emoji 头像、姓名、身份与身体状态合并为同一张角色状态卡。
- 身体状态四项数据增加与手机状态一致的图标：体力、药物负荷、信任和怀疑。
- “当前进度”从养成页和全局右栏移至“离院”页，并与离院条件清单合并显示。
- 手机顶部左侧加入游戏名称与署名，右侧继续保留今日状态和保存按钮。

## v1.7 晨间治疗与药物机制优化
- 手机顶部署名更新为“逃离疯人院 by Mootii”。
- 晨间治疗的三种选择形成明确取舍：配合服药能增加院方信任，少服或避开则更容易保持清醒，但会增加怀疑。
- 药物负荷达到 25 时进入“反应迟钝”：每次行动额外消耗 3 点体力，能力成长降至 80%。
- 药物负荷达到 50 时进入“强镇静”：每次行动额外消耗 6 点体力，能力成长降至 60%。
- 合法离院要求药物负荷低于 60，维修通道要求低于 35；结束一天后药物负荷会降低 14，玩家仍可通过安排时间恢复清醒。
- “养成”、今日状态、晨间治疗窗口和离院条件都会显示当前药物效果与限制。

## v1.8 关键物品与关系突破
- 普通聊天只能把角色关系提升到 30；完成每个角色的物品请求后，关系才能继续深入。
- 茶包、点心、笔记本和侦探小说分别对应老张、陈伯、小文和护士林的关系突破。
- 完成请求会获得专属资源：复写纸、袖珍手电、防水信封和复核申请表。
- 新增香皂，可用于降低怀疑并小幅增加信任。
- 收集三份关键证据后，必须消耗复写纸与防水信封，整理出“密封证据包”。
- 合法离院必须使用复核申请表取得正式复核资格，并准备密封证据包。
- 维修通道离院必须准备密封证据包、维修通道地图和袖珍手电。
- 复写纸、防水信封和袖珍手电也可以在小卖部购买，保留工作换资源的替代路线；复核申请表只能通过护士林获得。

## v1.9 晨间治疗界面优化
- 每天晨间治疗完成前，隐藏下方的玩法 Tips、行动地点和相关内容。
- 完成任意晨间治疗选择后，自动显示当天全部行动内容。
- 读取已经完成晨间治疗的存档时，行动内容会直接正常显示。

## v1.10 情报详情弹窗
- 获得普通线索、离院方案或关键证据时，立即弹出情报详情窗口。
- 弹窗显示情报图标、类型、名称和完整描述，关键证据使用更醒目的样式。
- 情报弹窗不会自动消失，也不能通过右上角按钮跳过；点击“确定”后才会关闭。
- 同一次事件连续获得多条情报时，会按获得顺序逐条展示。

- Pad 端说明文字不再使用 9–11px 的桌面微型字号，次要信息统一提高到至少 12px。

- 手机顶部游戏名、署名、今日状态和数值同步放大，并增加顶部区域高度避免拥挤。
- 日志正文提高到 15px，数值变化标签提高到 12px。
- 行动按钮和弹窗选项增加最小高度、内边距与行高，提升阅读和触控体验。

## v1.12 手机晨间治疗显示修复
- 修复手机端完成晨间治疗后，行动地点仍然保持隐藏的问题。
- 行动区改为独立的显式显示状态，同时同步控制隐藏属性、样式、状态标记和无障碍属性。
- 治疗选择完成后立即显示行动区，并在下一帧再次同步，避免移动浏览器延迟更新样式。
- 新的一天仍会正确隐藏行动区，读取已完成治疗的存档则会直接显示。

- 为 `game.js`、`style.css` 和 `enhancements.css` 增加 v1.13 加载标识，强制手机重新获取最新文件。
- 完成晨间治疗后，手机会自动把当天行动区滚动到可见位置。
- 首页“继续游戏”按钮改为深色文字，提高浅色按钮背景上的对比度。

## 推荐试玩策略
不要只追情报。工作、社交、信任、角色请求、关键物品、院外联络和体能都会影响最后能否真正离开。
